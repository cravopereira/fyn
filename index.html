Fyn

Fyn works on top of your Google Sheet. Your numbers stay in the sheet; this phone only keeps a copy to open fast.

Where do I find these?
  1. Open the sheet on a computer. Extensions › Apps Script.
  2. Add a file called Api and paste the code you were given. Save.
  3. Run createAppKey. Copy the key it shows.
  4. Deploy › New deployment › Web app. Execute as: Me. Who has access: Anyone. Copy the URL.
